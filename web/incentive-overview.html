一、四条激励赛道

赛道 A

方法学

把可验证减排路径固化为方法学，支撑复制与碳资产开发。

赛道 B

专利 / 软著

沉淀工艺、装备、监测与数字化知识产权，形成壁垒。

赛道 C

协会奖项

冲击省部级与行业协会奖，放大示范与品牌价值。

赛道 D

碳减排成效

按可核证 tCO₂e 计分，超额完成加权，结果导向兑现。

三、申报—入账—兑现闭环

1. 备案行动计划与目标
2. 实施取证台账 / 证书 / 数据
3. 审核职能初审 + 专家复核
4. 公示入账5 个工作日异议期
5. 兑付评优年度结算与授牌

四、与考核、人事、资源挂钩

对项目部

  • 绩效考核嵌入绿色低碳权重 5%–10%
  • 班子年终奖与 CP、减排目标完成率挂钩
  • 设立“绿色低碳示范项目部”专项评优
  • 高积分项目优先获设备、专家、科技经费

对个人

  • 碳管理员岗位津贴 300–800 元/月
  • 个人 ≥200 CP 评优加分；≥500 CP 优先推荐
  • 方法学 / 专利主要完成人计入科技业绩
  • 造假与重大事故：积分冻结 + 一票否决
