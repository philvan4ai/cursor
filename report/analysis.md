# 研究A：动力电池限制政策与气候装机目标的博弈分析

## 1. 叙事逻辑（对照研究B结构）

研究B的叙事是：**气候转型必要 → 金属供给可能卡住 → 既有情景/研究忽视或误设 → 技术灵活性可收缩瓶颈清单 → 仍需全经济节制**。  
研究A沿同一骨架展开，把「采矿能力」替换为「限制性产业政策的策略互动」，把「优化技术组合」替换为「求解政策—产业博弈均衡」。

### 1.1 对照式叙事

| 叙事环节 | 研究B | 研究A |
|---------|------|------|
| 规范前提 | 成功的能源转型对减缓气候变化至关重要 | 能源转型依赖电气化，动力电池是核心约束 |
| 威胁 | 关键金属供应瓶颈可能阻碍转型 | 各国为竞争优势出台关税、矿产保护、市场准入等限制政策，可能阻碍全球装机 |
| 对既有路径的批评 | IPCC 情景忽视金属风险；既往研究用固定市场份额，高估不可行性 | 气候情景（STEPS/APS/NZE）把装机当作外生需求目标，忽视各国产业政策的策略互动与碎片化 |
| 被忽视的调整机制 | 市场可转向更省金属的（次）技术组合 | 政策与产业份额会演化：开放/限制、一体化/碎片化并非固定 |
| 本文贡献 | 优化技术组合后，采矿受限金属从13种减至铜、锂、钒 | 用演化博弈求均衡装机 \(Q\)，并度量相对目标 \(Q^*\) 的缺口 |
| 残余问题 | 另有16种金属压力主要来自转型外部门 → 需全经济金属节制 | 气候收益是公共品，搭便车使限制竞赛可在高雄心下仍稳定 → 需气候—产业协同治理 |

### 1.2 研究A叙事正文（B式一段话）

成功的能源转型对减缓气候变化至关重要，但转型速度高度依赖动力电池装机的快速扩张。各国为推进电气化大力发展动力电池产业、提高产量；与此同时，为争夺市场竞争优势，又密集出台关税、关键矿产保护、市场准入与本地内容等限制政策。主流气候情景通常把所需装机量写成外生目标，却较少处理这些「本意服务转型」的产业政策经策略互动后如何分割供应链、抬高成本并压低全球有效供给——正是既往金属约束研究里「固定市场份额」一类简化在制度层面的对应物。在这里，我们对最严格的脱碳路径（及 STEPS/APS 对照）展示：一旦允许政策侧在开放与限制之间、产业侧在全球一体化与碎片化本地化之间演化，博弈均衡下的实际装机可显著低于情景目标；关键杠杆是关税—矿产—准入摩擦叠加、产业租金私有化与气候收益公共品属性所驱动的限制竞赛。协同治理虽能把均衡推回接近目标的装机水平，但在缺乏协调时，限制政策本身会成为气候目标的制度性瓶颈。

### 1.3 回答的核心问题

**研究B的核心问题：**  
在最严格脱碳情景下，引入技术灵活性后，还有哪些金属仍受采矿能力约束？还需要什么？

**研究A的核心问题：**  
在不同气候情景下，各国产业政策与电池产能策略互动收敛后，全球实际能实现多少动力电池装机？与情景目标装机的缺口有多大？

可操作的量化表述：

\[
\text{给定 }\alpha\in\{\mathrm{STEPS},\mathrm{APS},\mathrm{NZE}\},\quad
\text{求均衡 }(r^*,f^*)\ \Rightarrow\ Q(\alpha)=Q^*(\alpha)\cdot\eta(r^*,f^*,\tau,\mu,a),\quad
\Delta(\alpha)=Q^*(\alpha)-Q(\alpha).
\]

一句话：**B 回答「金属够不够、技术组合能省下多少」；A 回答「政策博弈后装机能装多少、缺口有多大」。**

### 1.4 机制映射

| 环节 | 机制 | 模型映射 |
|------|------|---------|
| 核心约束 | 电气化速度受电池供给约束 | 目标装机 \(Q^*(t;\alpha)\) |
| 扩产竞赛 | 产量扩张与产业租金绑定 | 产业租金、本地化补贴进入支付 |
| 限制政策 | 关税 \(\tau\)、矿产保护 \(\mu\)、准入 \(a\) | 外生工具路径 + 限制份额 \(r\) |
| 产量受损 | 碎片化抬高摩擦、重复建设 | 效率 \(\eta(r,f,\tau,\mu,a)\) |
| 气候偏离 | 实际装机落后于情景目标 | 缺口 \(Q^*-Q\)；气候惩罚仅部分内化 |

## 2. 博弈模型构建思路（公开数据驱动）

研究A不以抽象参数为起点，而以三类公开数据构造可观测状态、策略空间与支付，再进入均衡求解。

### 2.0 三层数据 → 模型对象

| 数据层 | 公开来源（示例） | 构造的模型变量 |
|--------|------------------|----------------|
| **技术（专利）** | IEA 电池专利报告 / PATSTAT / WIPO IPC（H01M 等电池族）；各国专利族数量、被引与化学路线结构 | 技术能力 \(T_i\)；路线结构（LFP/NMC/固态等）份额；技术差距 \(\Delta T_{ij}\) |
| **政策** | IEA Critical Minerals Policy Tracker；关税与贸易限制（WTO/Global Trade Alert）；本地内容/IRA/CBAM 类规则 | 限制强度向量 \(p_i=(\tau_i,\mu_i,a_i)\)：关税、矿产保护、市场准入 |
| **产量/产能** | IEA Global EV Outlook 电芯名牌产能与区域产量；各国装机/出口 GWh | 产能 \(K_i\)、产量 \(Y_i\)、全球份额 \(s_i\)；作为初值与校准锚点 |

玩家集合取主要电池生产与需求经济体（如中国、美国、欧盟、日韩，以及关键矿产出口国作扩展）。气候情景 \(\alpha\)（STEPS/APS/NZE）不来自专利，而来自 IEA 需求路径，作为外生需求移位器。

### 2.0.1 从数据到策略空间

每个国家 \(i\) 的策略不是“抽象开放/限制”，而是对可观测政策工具的选择：

\[
\sigma_i = (\tau_i,\ \mu_i,\ a_i,\ \ell_i)
\]

- \(\tau\)：关税/反倾销强度（贸易数据）
- \(\mu\)：矿产出口许可、配额、禁运（政策追踪器）
- \(a\)：市场准入 / 补贴本地含量门槛
- \(\ell\)：是否强制本地化产能（与 \(\tau,a\) 联动）

技术侧不直接作为“一步策略”，而作为状态：专利存量与结构决定本国在开放或限制下能兑现多少有效产能（有专利无产能、或有产能无上游矿产，支付不同）。

### 2.0.2 状态方程（数据校准的动态）

\[
\begin{aligned}
K_i(t+1) &= K_i(t) + \underbrace{\mathrm{Inv}(T_i,p_i,p_{-i})}_{\text{投资受技术与政策影响}} - \delta K_i,\\
T_i(t+1) &= (1-\rho)T_i(t) + \underbrace{\mathrm{RD}(K_i,p_i)}_{\text{专利/研发积累}} + \underbrace{\mathrm{Spill}(T_{-i},p)}_{\text{开放则溢出高、限制则低}},\\
Y_i(t) &= \min\bigl\{K_i(t),\ \mathrm{Input}(p_{-i},\text{矿产与中间品})\bigr\}\cdot \zeta(T_i).
\end{aligned}
\]

全球实际装机（研究A核心结果变量）：

\[
Q(t)=\sum_i Y_i^{\mathrm{deploy}}(t)
=\eta\bigl(\{p_j\},\{T_j\},\{K_j\}\bigr)\cdot Q^*(t;\alpha).
\]

其中 \(\eta\) 由限制政策造成的贸易摩擦、重复建设与投入品阻断内生决定——这正是对研究B中“固定技术份额”批评在制度维度的对应：市场份额与有效供给随策略而变。

### 2.0.3 支付函数如何接数据

国家 \(i\) 的单期支付分解为可对应数据的四项：

\[
\pi_i
= \underbrace{R^{\mathrm{ind}}(Y_i,s_i,p_i)}_{\text{产业租金：产量/份额}}
+ \underbrace{R^{\mathrm{sec}}(\mu_i,a_i)}_{\text{供应安全：矿产与准入}}
- \underbrace{C^{\mathrm{fric}}(p_i,p_{-i},T_i)}_{\text{摩擦成本：关税报复、技术封锁}}
- \underbrace{\phi_i\cdot \Lambda\bigl(Q^*-Q;\alpha\bigr)}_{\text{气候欠账：仅部分内化}}.
\]

- \(R^{\mathrm{ind}}\)：用当前产量份额与出口单价代理；
- \(R^{\mathrm{sec}}\)：用关键矿产净进口依赖度、政策工具计数代理；
- \(C^{\mathrm{fric}}\)：用双边限制叠加 × 技术差距代理（高 \(T_i\) 国家限制时，全球 \(Q\) 损失更大）；
- \(\phi_i\Lambda\)：气候情景目标与实现装机之差，\(\phi_i\) 为内化份额（公共品）。

### 2.0.4 均衡概念与求解路径

1. **静态基准（可先做）**：给定当期 \(\{T_i,K_i\}\)（专利+产能截面），各国同时选 \(p_i\)，求纳什均衡 \(p^*\)，计算 \(Q(p^*)\) 与缺口。  
2. **动态主模型（研究A主线）**：政策与产业策略的演化博弈 / 复制者动态，或有限理性最优反应学习；稳态 \((r^*,f^*)\) 或国家向量 \(p^*\) 对应长期装机。  
3. **气候情景扫描**：只改 \(Q^*(\cdot;\alpha)\) 与 \(\Lambda(\cdot;\alpha)\)，比较 STEPS/APS/NZE 下均衡装机。  
4. **反事实**：协同治理（提高 \(\phi_i\)、上限约束 \(\tau,\mu,a\)）vs 限制竞赛（历史政策路径外推）。

### 2.0.5 识别与校准顺序

```text
① 产量/产能截面  → 标定 K_i(0), s_i(0), Q(0)
② 专利存量与结构 → 标定 T_i(0), 技术差距与溢出弹性
③ 政策文本/工具库 → 构造 p_i(t) 指数，估计限制对贸易/装机的摩擦弹性
④ 气候情景        → 输入 Q*(t;α)
⑤ 矩匹配/网格校准 → 使模型再现近年份额演变与政策升级方向
⑥ 求均衡          → 报告 Q(α), Δ(α)=Q*-Q
```

这样，研究A的核心问题在数据上可表述为：  
**用专利、政策、产量三类公开数据标定国家异质性后，策略互动收敛的均衡装机 \(Q(\alpha)\) 能覆盖多少气候情景需求 \(Q^*(\alpha)\)？**

## 3. 模型结构（可计算简化版）

当前代码实现是上述思路的**两群体降维版**：把多国 \(p_i\) 压缩为限制份额 \(r\)，把产能布局压缩为碎片化份额 \(f\)，以便先得到可复现的定性均衡与缺口量级。完整多国版本按 §2.0 扩展即可。

### 3.1 两群体非对称演化博弈

| 群体 | 策略 | 状态变量 |
|------|------|---------|
| 主要经济体（政策侧） | 开放合作 \(O\) / 保护限制 \(R\) | \(r=\) 选择限制的份额 |
| 电池产业（产能侧） | 全球一体化 \(G\) / 碎片化本地化 \(F\) | \(f=\) 选择碎片化的份额 |

气候情景强度 \(\alpha\in\{\mathrm{STEPS},\mathrm{APS},\mathrm{NZE}\}\) 同时决定：

1. 目标装机路径 \(Q^*(t;\alpha)\)（以 2023 年约 750 GWh 为基，2030 年分别约 ×4.5 / ×5 / ×7）；
2. 气候欠账进入政策支付的权重。

关键公共品设定：气候收益具有全球公共品属性，各国仅内化份额 \(\phi\)（搭便车）。因此即便处于 NZE，单独开放的激励仍可能不足，限制竞赛可成为演化稳定结果；协同治理情景则把 \(\phi\) 抬高，使开放重新占优。

### 3.2 装机映射

\[
Q(t)=Q^*(t;\alpha)\cdot\eta(r,f,\tau,\mu,a),\qquad
\eta=\frac{1}{1+\text{摩擦}(r,f,\tau,\mu,a)-\text{本地化有限对冲}}
\]

缺口 \(\mathrm{Gap}=Q^*-Q\) 既是气候绩效指标，也反馈进入政策支付。

### 3.3 复制者动力学

\[
\begin{aligned}
\dot r &= \alpha_r\, r(1-r)\,[\pi_R-\pi_O],\\
\dot f &= \alpha_f\, f(1-f)\,[\pi_F-\pi_G].
\end{aligned}
\]

时间单位：年，\(t=0\) 对应 2023，\(t=7\) 对应 2030。

### 4.1 2030 博弈平衡点（装机，TWh）

| 情景 | 目标 \(Q^*\) | 均衡装机 \(Q\) | 缺口 | 限制份额 \(r\) | 碎片化 \(f\) |

| 限制竞赛 × STEPS | 3.38 | 1.76 | 48% | 87% | 91% |
| 限制竞赛 × APS | 3.75 | 1.97 | 48% | 83% | 88% |
| 限制竞赛 × NZE | 5.25 | 2.81 | 46% | 73% | 80% |

### 4.2 政策悖论的定量含义

在 NZE 路径上，限制竞赛相对开放合作：

- 2030 实际装机由约 **4.93 TWh** 降至约 **2.81 TWh**（损失约 **43%**）；
- 气候装机缺口额外扩大约 **2.12 TWh**。

即：气候雄心越高，目标装机越大；若限制竞赛锁定为均衡，绝对缺口反而更大——这正是「助力转型的政策阻碍气候目标」的形式化表达。

## 5. 政策含义

1. **产业政策 ≠ 气候政策**：关税、矿产保护与市场准入可提升本国产业租金，但经策略互动后会系统性压低全球有效装机。
2. **NZE 不能自动纠正碎片化**：因气候收益是公共品，搭便车使限制竞赛在高雄心情景下仍可稳定；需要把气候成本显式内化到产业政策规则中。
3. **协同治理的杠杆**：提高气候收益内化份额 \(\phi\)、降低报复性准入壁垒，可使均衡从高 \(r,f\) 转向接近开放路径，装机逼近 \(Q^*\)。
4. **矿产硬保护是高杠杆摩擦**：对上游的突然收紧，会把碎片化推向角点，缺口超过温和本地内容情景。

## 6. 模型边界

- 将多国战略互动压缩为两群体演化份额，不识别单一国家最优关税。
- 气候情景目标装机取 IEA 倍率中枢，非完整能源系统联立求解。
- 结论强调**序数关系与数量级**：开放 > 温和限制 > 限制竞赛；NZE 下限制竞赛绝对缺口最大。
- 未内生技术路线（钠电、固态）突破；可类比为外生降低摩擦的反事实。

---

## 7. 一句话结论

动力电池限制政策在国家竞争逻辑下容易演化为碎片化均衡，使全球实际装机系统性低于气候情景所需水平；不同气候情景改变的是目标高度与缺口规模，而不自动消解这一博弈困境。
