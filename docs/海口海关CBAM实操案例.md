# 海口海关场景：出口欧盟CBAM实操案例

实操案例：海口海关监管下，一批海南铝材出口欧盟

场景不设在欧盟口岸“收碳关税”，而设在中国出口端——因为CBAM的证书购买与缴销发生在欧盟进口侧；海口海关的实操重点是：把货认准、单证做实、把企业辅导到位，让对方进口商能合规清关，避免到港卡壳。

一、案情
海南某铝加工企业经海口口岸申报出口铝合金型材500吨至荷兰鹿特丹，境外收货人为荷兰进口商。货物属于欧盟CBAM覆盖的铝及相关制品范围。企业按出口报关流程向海口海关申报。

二、海口海关侧实操步骤
1. 归类与清单识别：关员指导企业核对税则编码，确认是否落入CBAM附件商品范围；编码错报会导致欧方认定偏差，是后续纠纷高发点。
2. 原产地与成交信息：审核原产地声明/证书、数量、单价、生产商信息，确保与合同、发票、箱单一致，便于欧方追溯“嵌碳”对应的生产设施。
3. 出口通关与监管证件：完成查验、放行等常规监管；CBAM本身不在海口征收，不增加国内“碳关税税单”。
4. 合规辅导（关键增值）：约谈企业说明——荷兰进口商须具备授权CBAM申报人资格；需企业配合提供实际嵌入排放数据（或接受欧方默认值，通常更严更贵）；若相应工序已纳入中国全国碳市场等强制履约并有净实付碳价，应准备清缴证明、免费配额扣减说明等，供欧方申请“原产国已付碳价”扣减。自愿碳汇、绿证一般不能充当该扣减。

三、链路如何闭环
海口放行后，货物到鹿特丹：欧方海关通关 + 进口商按嵌入排放购买/缴销CBAM证书；能证明在中国强制碳价机制（如全国碳市场ETS）上净实付的，可申请少缴部分证书；证明不足则近似按欧盟碳价补齐。海口海关不替代欧方审碳账，但出口归类不准、生产商信息不清、排放与碳价证据缺失，会直接变成“到港成本飙升或放行受阻”。

四、一句话 dual 职责
海口海关管“出得去、证相符、企业懂规则”；欧盟管“授权申报、碳账与证书”。对中国企业，海口场景的实操抓手就是：归类正确、原产地清晰、排放与碳市场履约证据早准备。
