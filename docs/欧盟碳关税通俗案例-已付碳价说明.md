# 欧盟碳关税通俗案例：原产国已付碳价说明

通俗案例：一船韩国螺纹钢进汉堡港，碳价怎么算？

假设德国某建材进口商从韩国采购1000吨螺纹钢（属于CBAM覆盖的钢铁类商品）。货到欧盟后，海关照常办通关：归类、原产地、关税增值税该怎么走还怎么走。CBAM是另一件事——进口商还得当“授权CBAM申报人”，按这批钢里“嵌着的二氧化碳”去买并缴销CBAM证书，价钱大体跟着欧盟碳市场（EU ETS）走。好比欧盟本地钢厂已经为排放买过碳，进口钢也要补齐差不多的碳成本，免得外面便宜高碳货把产业“漏”出去。

“原产国已付碳价”指什么？不是口头说交过环保费，而是原产国依法、实际掏过的显性碳价格，主要就两类：
1. 碳交易机制（ETS）：企业为生产排放上缴/购买配额，如韩国K-ETS、英国UK ETS等强制排放权交易；
2. 碳税/碳费：按排放量征收的税、费、征费。
自愿购买的碳汇、绿证、一般能源税或环保罚款，通常不算这笔可扣减的“碳价”。若企业拿过免费配额、退税、返还，还要扣掉，只认“净实付”。

落到这个案例：韩国钢厂若已在K-ETS为相应排放清缴配额，德国进口商凭独立核验材料，可在CBAM申报里申请少缴一部分证书，避免“韩国交一次、欧盟再全额交一次”。若同样钢来自尚无覆盖该工序强制碳价的国家，或只有默认排放因子、拿不出实付证明，就基本按欧盟碳价全额补。对中国货也同理：全国碳市场等属于ETS类型，但能否扣减，要看该产品嵌入排放是否真正落在已强制履约的行业/设施上，并提供实付与扣减免费配额后的证据——有覆盖、有实付、有证明，才能减；没有，就不能减。

海关记住一句话：通关看归类与授权资格；碳账看嵌入排放；能少买证书的，只认原产国ETS或碳税上的净实付碳价。
