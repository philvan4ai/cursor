# 实际嵌入排放与“原产国已付碳价”扣减：展开举例

承接海口海关铝材出口欧盟场景，把两句话拆开说明：企业要交什么数据、什么叫净实付、欧方怎么用来少买CBAM证书。

---

## 一、先分清两套账

| 账本 | 谁用 | 干什么 |
|------|------|--------|
| A. 实际嵌入排放 | 欧方算应缴CBAM证书数量 | 这批出口商品“嵌”了多少 tCO₂e |
| B. 原产国已付碳价 | 欧方申请少缴部分证书 | 同一批排放在中国强制碳价机制里净实付了多少钱 |

A决定“按欧盟碳价大概要补多少”；B决定“因为国内已经交过，可以少补多少”。两套材料都要企业配合提供，但用途不同。

---

## 二、“实际嵌入排放”展开说明

### 2.1 通俗含义

不是企业全年排了多少碳，而是：**这一票出口货，在生产过程中对应摊到的温室气体排放**。对铝材，通常要看到电解铝、铸造/挤压等关键工序的直接排放，以及规则要求计入的间接排放（如外购电，视CBAM对该品类的具体规则）。

### 2.2 企业通常要准备的材料（举例）

以“海口出口500吨铝合金型材至荷兰”为例，出口企业（或上游纳入全国碳市场的铝冶炼重点排放单位）宜整理：

1. **生产边界说明**：哪座电解铝厂、哪条铸造/加工线、对应炉号或批次；  
2. **活动数据**：该批次铝水/锭/型材产量、燃料消耗、电极消耗、外购电量等；  
3. **排放因子与计算书**：按行业核算指南算出该批次 tCO₂e，并折成**吨产品嵌入排放强度**（tCO₂e/吨铝）；  
4. **质量证明**：月度存证、年度排放报告、核查机构意见（能对应到设施更好）；  
5. **货票对应关系**：报关数量、合同批次、出入库单，证明“报关的500吨”能勾到上述计算。

拿不出实际数据时，欧方可能用**默认值**，往往偏保守（偏高），进口商要买更多证书，成本更高。所以“配合提供实际嵌入排放”本质是：**用可核验的真实强度，替换更贵的默认强度**。

### 2.3 数字小品（示意，非实测）

假设经核算，该批次实际嵌入排放强度为 **12 tCO₂e/吨铝**（示意）。  
出口500吨 → 申报嵌入排放约 **6000 tCO₂e**。  
若欧方CBAM证书价格按 **75欧元/tCO₂e**（示意），未扣减前证书义务大约对应 **6000×75 = 45万欧元**量级。  
若改用更高默认值（如15 tCO₂e/吨），则为 **7500×75 = 56.25万欧元**。  
两者相差约11万欧元。可见：实际强度每低1吨碳/吨产品，500吨货大约少约 **3.75万欧元**量级成本（随碳价波动）。海关培训时可强调：数据质量直接等于欧方落地成本。

## 三、“全国碳市场强制履约 + 净实付”展开说明

### 3.1 指哪种机制

这里的“强制履约”主要指中国**全国碳排放权交易市场（全国碳市场，ETS）**：发电及已纳入的钢铁、水泥、**铝冶炼**等重点排放单位，按年获得配额、交易配额，并在规定时限前向省级生态环境部门**清缴与经核查排放量相当的配额**。

它属于CBAM规则里可讨论的“排放权交易体系下的配额支出”这一类显性碳价；**不是**企业自愿买的绿证、普通碳汇宣传项目。能否被欧方最终认可扣减，还要以欧盟实施细则与独立核证要求为准，但企业准备方向就是：**ETS清缴实付证据 + 扣掉免费配额/返还后的净额**。

### 3.2 什么叫“净实付”（最容易讲错的点）

全国碳市场常有**免费配额**。举例（示意）：

- 某铝冶炼重点排放单位某履约年度经核查排放 **100万吨**；  
- 获免费配额 **95万吨**；  
- 缺口 **5万吨**，从市场买入后完成清缴。

则：

- **名义碳约束**覆盖100万吨；  
- **净实付碳价**主要体现在买入并用于清缴的那 **5万吨**（外加若存在的有偿分配支出等）；  
- 免费到手的95万吨，一般**不能**再拿去跟欧方说“这95万吨也付过钱了”。

若还有返还、补助、补偿把实际负担冲掉，同样要从可主张金额里扣除。口诀：**只认掏过真金白银、且对应到申报嵌入排放上的净负担。**

### 3.3 清缴证明准备什么（给欧方申请扣减用）

建议企业（或上游冶炼厂）打包“履约证据包”，供荷兰授权CBAM申报人使用：

1. 重点排放单位身份与行业纳入证明（名录/主管部门文件）；  
2. 该履约年度**履约通知书/应清缴量**；  
3. **清缴完成证明**或注册登记系统履约记录（注登机构/主管部门出具的履约证明）；  
4. 配额账户流水：免费配额到账、外购配额、清缴划转；  
5. 外购配额的成交均价或发票、结算单（用于换算已付货币碳价）；  
6. **分摊说明**：如何把年度设施层面的净实付，合理分摊到本票出口500吨铝材对应的嵌入排放上（按产量、按批次物料平衡等），并保留可复核计算表；  
7. 按欧方要求由**独立第三方**出具的核证/鉴证意见（具体以欧盟实施规定为准）。

海口海关不审这套碳账是否获欧方通过，但可在辅导中告知：缺第6步“出口批次分摊”，即使厂里履约了，进口商也很难主张扣减。

### 3.4 数字小品：扣减怎么影响证书

承接上文，申报嵌入排放 **6000 tCO₂e**。  
经分摊，本票货对应的“净实付”假设折合 **20欧元/tCO₂e**（示意：仅缺口配额外购成本摊到产品后的均价）。  

示意逻辑（非官方公式，便于理解）：

- 未扣减：按欧盟价75，义务很重；  
- 有净实付后：相当于这6000吨里已有一部分碳成本在中国付过，欧方允许**少缴相应数量的CBAM证书**，避免双重收费；  
- 免费配额占比越高，净实付越低，可扣减空间越小；  
- 若该铝加工厂本身不是重点排放单位，但上游电解铝厂是，则要打通**供应链数据**：加工商向冶炼厂取排放与履约证明，再对应到出口批次。

## 四、一张图看懂企业配合事项（海口出口场景）

1. 报关前：定货源厂是否全国碳市场重点排放单位（铝冶炼等）。  
2. 算清楚：本票货实际嵌入排放（强度×净重）。  
3. 找得出：对应履约年度清缴记录与外购配额成本。  
4. 摊得下：净实付如何摊到本票500吨。  
5. 交得过：材料给荷兰授权申报人，由其向欧方主张扣减。  
6. 海口海关：归类、原产地、生产商信息准确 + 合规宣讲；碳账认可在欧盟。

---

## 五、培训口令（可直接讲）

- **实际嵌入排放**：把“这船货”的碳算清楚，用来替代更贵的默认值。  
- **净实付**：全国碳市场里真正花钱清缴的部分，免费配额要刨掉。  
- **清缴证明**：履约完成证明 + 配额流水 + 批次分摊 + 独立核证材料。  
- **目标**：欧方少买CBAM证书；不是海口海关减税。
