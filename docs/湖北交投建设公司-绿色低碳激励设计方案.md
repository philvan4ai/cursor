# 湖北交通投资集团建设公司  
# 施工项目绿色低碳激励设计方案  
## ——以“求名”为核心的荣誉驱动机制（论述稿）

> 版本：V2.0（荣誉导向修订版）  
> 定位：管理论述与制度设计文本，不涉及信息系统开发  
> 核心判断：**项目部不缺钱，只求名。** 激励应少谈奖金，多给名分、署名、授牌、榜单与行业声望。

---

## 一、问题重述：钱不是痛点，名才是激励点

湖北交投建设公司推动施工项目采用绿色低碳技术，目标很清楚：减排见效，并沉淀为方法学、专利、协会奖项等可对外展示的成果。

若按常规“发钱激励”设计，容易失灵。原因不在预算，而在动机结构：

1. **项目部资金相对充裕**，小额奖金对班子决策几乎没有边际刺激；  
2. 真正稀缺的是**被看见、被承认、被记录、被传播**的组织声誉与个人名望；  
3. 绿色低碳工作往往“做了没人知、知了难评优、评优难留名”，导致投入热情不足。

因此，本方案把激励主轴从“兑钱”转为“成名”：

- 让项目部因低碳实践获得**可悬挂、可写入履历、可对外宣传**的荣誉；  
- 让骨干因方法学、专利、奖项获得**清晰署名与长期声誉资产**；  
- 让公司用**授牌、榜单、典范命名、行业推送**替代现金刺激，撬动持续行动。

一句话：**不发红包，发名声；不拼奖金厚度，拼名号分量。**

---

## 二、设计原则：名要真、名要早、名要久、名要公

### 2.1 名要真

荣誉必须对应可核验的减排成效或成果产出，禁止空转评优。没有台账、没有证据、没有审查，就不能授牌、不能上榜、不能署名发布。

### 2.2 名要早

专利受理、方法学立项、阶段减排达标等节点，应及时给予**阶段性荣誉认可**（通报表扬、季度上榜、专项提名），避免“跨年才看见”导致动力衰减。

### 2.3 名要久

把荣誉沉淀为长期资产：示范项目部牌匾、方法学冠名、专利发明人名单、典型案例库署名、年鉴与官网专栏。名声应能“留下来”，而不是一次性口头表扬。

### 2.4 名要公

公示、公开、公开场合授牌。名若不公开，就不成其为名。公司内部宣传、集团简报、协会论坛、行业媒体，是荣誉兑现的必要渠道。

### 2.5 名可分层

项目部求集体之名，骨干求个人之名。激励要同时满足：

- 项目部要“这块牌子挂得出去”；  
- 个人要“这份材料写进职称与履历”。

## 三、总体思路：四条成名赛道 + 一套荣誉阶梯

### 3.1 四条成名赛道

| 赛道 | 项目部得到的“名” | 个人得到的“名” |
|------|------------------|----------------|
| A. 方法学 | “某某减排方法学”由本项目验证/牵头，可对外发布 | 编写人、审定参与人正式署名 |
| B. 专利/软著 | 项目作为完成单位出现在证书与宣传中 | 发明人/设计人依法署名 |
| C. 协会与政府奖项 | 获奖项目、示范工程、典型案例称号 | 主要完成人进入获奖名单 |
| D. 减排成效 | 低碳示范工地、减排标杆项目部授牌与榜单 | 碳管理员、技术负责人评优提名 |

四条赛道不是四套奖金制度，而是**四条通往名声的路径**。公司的职责是：帮项目部把路走通、把名做实、把名传开。

### 3.2 荣誉阶梯（建议）

设置清晰、可攀登的名号层级，使项目部始终知道“下一档名声是什么”：

1. **绿色低碳达标项目部**（入门名号）：完成必做清单与基础盘查；  
2. **绿色低碳先进项目部**（年度评优）：减排达标且有专利/方法学/案例之一；  
3. **绿色低碳示范项目部**（核心名号）：授牌、官网专栏、集团推荐；  
4. **绿色低碳标杆项目部**（最高内部名号）：可冠名案例、优先冲击省部级/协会奖；  
5. **行业示范 / 协会获奖项目**（外部名号）：公司全力助推，形成对外品牌。

阶梯的意义在于：把“求名”变成可见的攀登游戏，而不是年底一次性抽奖。

## 四、公司向项目部提供什么：不是钱，是“成名服务”

项目部缺的不是经费，缺的是**专业包装、权威背书、公开舞台、稳定署名规则**。公司应提供以下成名服务包。

### 4.1 方法学成名服务

- 提供方法学写作模板、专家辅导、内部审查；  
- 通过后以公司/集团名义支持对外发布、备案或行业交流；  
- **方法学命名规则**：允许“技术方向 + 牵头项目部/完成人”的规范署名，例如在发布说明、编制说明中明确牵头项目与主要编写人；  
- 被其他项目复制应用时，原牵头项目部保留“首创验证单位”名誉标注。

方法学的激励本质是：**把工地经验写成行业话语，并把名字写进行业话语。**

### 4.2 专利成名服务

- 开通绿色低碳专利快速辅导通道（创意受理、代理对接、材料打磨）；  
- 公司承担必要的代理与官费支持（这是成事成本，不是发钱激励）；  
- 严格保护发明人署名顺序，证书复印件进入个人业绩档案；  
- 授权后在公司科技光荣榜、年度科技创新通报中点名表彰；  
- 转化应用时标注“源自某某项目部某项专利”。

对求名者而言，专利的价值首先是**署名权与专业身份**，其次才是可能的奖金。

### 4.3 奖项成名服务

- 发布年度“可冲击奖项清单”与申报日历；  
- 对高潜力项目提前组建申报专班，统一打磨材料、视频、数据；  
- 获奖后 15 个工作日内完成：授牌仪式、集团/公司官网与公众号专题、简报专送、荣誉墙更新；  
- 将协会奖、政府奖、示范工程称号作为最高外部名声，内部评优为其预热与输送。

奖项赛道是“求名”的主战场：公司要做的是**帮项目部把奖拿到、把名传开**。

### 4.4 减排成效成名服务

- 统一核算口径，使“减排多少”可比较、可上榜；  
- 季度发布《绿色低碳荣誉榜》（减排强度改善、措施创新、数据质量）；  
- 年度举行授牌典礼：示范项目部、标杆项目部、优秀碳管理员；  
- 优秀做法进入《绿色低碳典型案例集》，案例标题与完成单位永久留名。

没有公开榜单，减排就只是成本项；有了榜单，减排才成为名声竞赛。

## 五、“名”的具体兑现方式（荣誉工具箱）

下列工具可组合使用，原则上**以公开荣誉为主，不以现金为主**。

### 5.1 授牌与命名

- 实物牌匾：绿色低碳示范/标杆项目部；  
- 工地入口、会议室、荣誉墙规范悬挂；  
- 允许在项目宣传展板、迎检材料中使用统一荣誉标识；  
- 对特别突出者，给予案例冠名或方法学编制名义上的牵头标注。

### 5.2 榜单与公示

- 季度荣誉榜、年度光荣册；  
- 公司官网/内网专栏“双碳先锋”；  
- 集团层面推荐报送，争取更大范围点名。

### 5.3 典礼与舞台

- 年度绿色低碳表彰会（可并入科技大会或年会专场）；  
- 安排示范项目经理作经验发言；  
- 推荐参加协会论坛、行业观摩、标准研讨，给予“出镜”机会。

### 5.4 履历与组织承认

- 荣誉与署名写入项目班子业绩档案；  
- 作为评先评优、职称推荐、职级晋升的**优先参考条件**（不是买来的加分费，而是组织承认的声誉记录）；  
- 个人证书、奖牌、完成人名单复印件归档，随时可用于申报更高层级奖项。

### 5.5 传播与背书

- 统一宣传口径，由公司品牌/科技部门协助撰写通稿；  
- 向协会、媒体、上级单位推送典型；  
- 对外宣传必须点项目部之名、点主要贡献者之名，杜绝“公司有名、项目无名”。

### 5.6 资源型名誉支持（非奖金）

项目部不缺钱，但缺“能把名做大”的稀缺资源：

- 优先获得外聘专家辅导、第三方核证支持、奖项申报专班；  
- 优先作为上级检查、行业观摩、媒体采访的接待与展示点；  
- 优先纳入集团示范创建和对外交流名单。

这些支持的本质仍是成名，而不是发钱。

## 六、荣誉认定规则：先有实绩，才有名声

### 6.1 项目部入门门槛（无名则先达标）

未完成下列事项，不授予先进及以上荣誉：

1. 明确项目碳管理责任人；  
2. 编制绿色低碳行动计划与目标；  
3. 建立油、电及主要排放相关台账；  
4. 按季度报送执行情况。

### 6.2 成果类荣誉的证据要求

| 类型 | 认定依据 |
|------|----------|
| 方法学 | 文本、内审意见、发布/交流证明、应用验证数据 |
| 专利/软著 | 受理或授权文件、发明人确认、完成单位信息 |
| 奖项 | 证书、公示文件、申报材料归档件 |
| 减排成效 | 核算书、原始台账、必要抽核或第三方意见 |

### 6.3 署名与归属

- 申报前明确完成单位与完成人顺序，公示后原则上不随意变更；  
- 联合攻关可共享名誉，但须事先书面约定，避免事后争名；  
- 反对“搭车署名”和“有名无实”，一经查实撤销荣誉并通报。

### 6.4 撤销与一票否决

发生安全生产环保重大事故、减排数据造假、严重弄虚作假的，撤销相关荣誉称号，移出榜单，并取消当年评优资格。名声机制必须有退出，才有公信力。

## 七、组织角色：谁来“给名”、谁来“助名”

| 主体 | 责任 |
|------|------|
| 公司领导层 | 出席授牌、审定示范/标杆名单，赋予荣誉以权威 |
| 科技管理部门 | 方法学、专利、奖项辅导与材料把关 |
| 安全环保管理部门 | 减排核算真实性、监测与抽核 |
| 人力资源部门 | 将荣誉衔接到评优、职称、干部业绩档案 |
| 品牌/综合宣传 | 典礼、通稿、专栏、对外传播 |
| 项目部 | 出成果、出数据、出可传播故事；对真实性负责 |

公司不是向项目部“买行为”，而是为项目部**鉴证贡献、授予名分、放大声量**。

---

## 八、年度运转节奏（纯管理流程，无系统开发要求）

可采用表格与公文运转，不必建设专项信息系统。

1. **年初**：公布荣誉阶梯、奖项日历、案例征集方向；  
2. **季度**：核查台账，更新荣誉榜，通报表扬阶段性成果；  
3. **半年度**：组织案例分享会，遴选冲击协会奖的重点项目；  
4. **四季度**：综合评定达标/先进/示范/标杆，准备授牌；  
5. **次年年初**：表彰典礼、案例集发布、向上推荐、启动新一年冲击计划。

碳积分若保留，只宜作为**内部排序与评优门槛的计量尺**，用于“谁更有资格得名”，不宜设计成现金兑换券。没有积分也可以，直接用评级与榜单操作。

---

## 九、试点建议：先把“名”做出感觉

选择 2–3 个代表性项目试点，重点验证：

1. 授牌与公开表彰是否真正激发项目班子重视；  
2. 方法学/专利署名规则是否清晰、少争议；  
3. 奖项专班能否在一年内形成可申报材料；  
4. 典型案例传播后，其他项目部是否主动跟进“求名”。

试点成功标准不应看发了多少钱，而应看：

- 是否出现可对外讲述的示范样板；  
- 是否形成至少 1 项可发布方法学或可申报高级别奖项的成果包；  
- 项目班子是否主动要名号、要专栏、要推荐，而不是被动应付检查。

## 十、论述结论

对湖北交投建设公司施工项目部而言，绿色低碳激励的有效解不是加薪包，而是荣誉制度：

1. **用荣誉阶梯替代奖金菜单**，让项目部追逐示范、标杆与行业奖；  
2. **用署名与授牌替代现金分成**，让贡献写进证书、牌匾、案例集与履历；  
3. **用成名服务替代发钱刺激**，公司负责辅导、鉴证、申报、传播；  
4. **用公开榜单与典礼制造竞争**，让减排与创新成为看得见的名声竞赛；  
5. **用真实性门槛守护名的成色**，无名可缓，名不虚授。

最终形成的文化应是：

> 谁把低碳做成方法、写成专利、拿回奖项、做成示范，谁就在公司系统里被点名、被记录、被推荐——这就是项目部最想要的激励。
