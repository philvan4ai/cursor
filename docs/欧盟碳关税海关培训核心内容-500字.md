# 欧盟碳关税（CBAM）海关培训核心内容（一段话，约500字）

海关培训核心内容（欧盟碳关税/CBAM）：欧盟碳边境调节机制自2026年1月1日起进入正式实施期，本质是给进入欧盟的高碳进口商品补上一层与欧盟碳排放交易体系（ETS）相当的碳成本，防止“碳泄漏”，不是替代关税或增值税，而是叠加在通关之外的合规与缴费义务。现行覆盖水泥、钢铁、铝、化肥、电力、氢等附件清单商品，海关须先按税则编码准确归类识别是否属于CBAM货物。核心义务在进口方：年进口量超过约50吨门槛（电力、氢不适用该豁免）的，须取得“授权CBAM申报人”资格后方可放行相关货物；申报人需核算或采用默认值确定嵌入排放，购买并按年缴销CBAM证书，证书价格挂钩ETS碳价，原产国已付碳价可扣减。对海关培训要抓住四件事：一是清单识别与归类，避免漏判错判；二是核对申报人授权状态与代理安排，无资格不得按正式机制进口超门槛货物；三是单证与数据链——原产地、数量、嵌入排放证明、已付碳价证据须可追溯；四是与国税/主管机关协同，分清“通关放行”与“证书缴销”职责界面。培训落点是：海关不替代碳核算，但必须守住“认得出、拦得住、转得顺”，防止未授权进口与伪报归类成为合规缺口。
