# 答疑：12强度谁测、欧方认不认；扣减扣的是量还是钱

## 1. “12 tCO₂e/吨”是谁测的？欧方会认同吗？

**先说清楚：前文的12是教学示意，不是某个官方机构发布的标准强度，也不能直接拿去报CBAM。**

实际嵌入排放通常这样来：

1. **算：生产设施（厂）自己按规则核算**  
   由纳入管理的生产运营方（如铝冶炼重点排放单位/出口商指定的生产商）按欧盟CBAM监测核算方法，用产量、燃料、电力等活动数据算出该产品（或前体）的嵌入排放强度。

2. **核：具备资质的核查/验证机构做独立验证**  
   走“实际排放”路径时，一般需由欧盟认可规则下的**独立验证方**验证；不是海口海关测，也不是随便一家检测所盖章就自动生效。具体名录与认证要求以欧盟现行实施规定为准。

3. **认：欧盟主管机构+授权CBAM申报人采用**  
   荷兰等成员国主管机关通过CBAM登记系统受理申报；海关侧重货物放行与授权身份，碳账主要由CBAM体系审。  
   **认同的是“方法合规 + 数据可验证 + 验证有效”**，不是认同某一个中国机构“公布的行业平均12”。

若厂算不清或验证不足，欧方可用**默认值**（往往更保守/更高）。中国全国碳市场的核查报告有助于企业管理排放，但**不等于自动替代CBAM验证**；两者可衔接证据，最终仍要满足欧方CBAM口径。

## 2. 扣减减的是碳排放量，还是直接减钱？

**机制上：减的是应缴销的CBAM证书数量，不是海关税单上直接划掉一笔欧元。**

更细一点：

| 项目 | 怎么处理 |
|------|----------|
| 申报的嵌入排放量 | 仍按实际（或默认）排放申报，**一般不因为国内付过碳就把排放“改小”** |
| 原产国已付碳价扣减 | 按规则折算后，**少交/少缴销相应数量的CBAM证书** |
| 钱的效果 | 证书有价格（挂钩EU ETS），少交证书 → **花钱变少**，这是结果，不是“减税式直接减钱” |

通俗比喻：  
欧方先问“这批货嵌了多少碳”（排放账）；再问“这些碳在中国强制碳价里净实付了多少”（碳价账）。排放账照记；碳价账成立，就允许你**少买几张碳票（证书）**，从而少花钱。  
不是把6000吨嵌碳改成5000吨报关，也不是在关税里直接减免等额欧元。

口令：  
**排放照报；扣减减证书张数；少花钱是结果。**
