# 因子筛选与因子智能合成

> 本文是智能量化策略设计框架的因子层专题说明：回答「是什么、为什么重要、怎么做」，并把**筛选**与**智能合成**放在同一条可审计流水线里。

---

## 1. 先给结论

**因子筛选**解决的是：从海量候选里留下「真有信息、可交易、不过度相关」的因子。  
**因子智能合成**解决的是：把留下的因子，按可解释、可约束、可自适应的方式，合成一个（或少数几个）更强、更稳的综合因子/信号。

二者不是替代关系，而是前后衔接：

```
候选因子池
  → 清洗与标准化
  → 单因子评估与多重检验          【筛选：去伪存真】
  → 冗余压缩与增量贡献检验
  → 智能合成（加权 / 正交 / 状态条件 / 学习型）【合成：聚沙成塔】
  → 合成因子再验收（样本外 + 成本后）
  → 输出给策略生成引擎
```

没有严格筛选的合成，容易把噪声放大成「看似很强」的过拟合信号；  
没有智能合成的筛选，容易停在一堆弱相关单因子，无法形成稳定可执行 alpha。

---

## 2. 因子筛选是什么

### 2.1 定义

因子筛选（Factor Screening）是一套**证据驱动的准入与淘汰机制**：对每个候选因子，在统一宇宙、统一滞后规则、统一成本假设下，评估其预测力、稳定性、可交易性与独立性，决定：

- 入选（进入生产因子库）
- 观察（样本外继续跟踪）
- 降权（仍可用但降低影响）
- 淘汰（下架或禁止进入合成）

它不是一次性排名，而是**生命周期管理**：入库、监控、衰减、复活、退役。

### 2.2 筛选要回答的六个问题

| 问题 | 含义 | 典型证据 |
|------|------|----------|
| 有没有预测力？ | 因子与未来收益是否相关 | RankIC、ICIR、分层多空收益 |
| 是不是运气？ | 显著性是否经得起多重检验 | p 值、BH/BY-FDR、置换检验 |
| 稳不稳？ | 不同时段/市场状态是否仍有效 | 滚动 IC、分年度/分 regime 检验 |
| 能不能交易？ | 覆盖、换手、成本后是否仍成立 | 覆盖率、换手、冲击敏感度 |
| 是不是重复？ | 相对存量因子是否提供新信息 | 相关矩阵、VIF、增量 R² |
| 风险是否可控？ | 是否只是风格/行业的马甲 | 中性化后 IC、风格暴露 |

### 2.3 和「挖因子」的区别

- **挖因子**：尽量提高样本内表现，容易过拟合。  
- **筛因子**：尽量提高「样本外仍可信、实盘可落地」的概率。  

筛选的目标函数不是「IC 最大」，而是「在可控风险与可交易成本下，信息质量期望最大」。

## 3. 为什么因子筛选重要

### 3.1 直接决定后续链路上限

策略生成、仓位优化、净值风控都建立在因子之上。  
若上游因子是噪声、滞后错误、或高度拥挤，下游再精巧的组合优化也只是在放大错误。

### 3.2 控制多重检验与数据挖掘偏差

现代因子研究常见「万级候选」。若不做 FDR / 样本外分片，大量「显著因子」其实是假阳性。  
筛选把**错误发现率**变成一等公民约束。

### 3.3 控制冗余与拥挤

高度相关的因子一起进模型，会造成：

- 表面权重分散、实际风险集中
- 换手虚高
- 拥挤交易共振（同向调仓）

筛选通过相关性压缩与增量贡献检验，避免「看似多因子、实质单因子」。

### 3.4 连接研究与生产

筛选输出不是一张漂亮表格，而是生产契约：

- 哪些因子可被策略引用
- 中性化与滞后规则是什么
- 失效阈值与自动降权规则是什么

没有这层契约，回测与实盘很容易「研究一套、上线另一套」。

## 4. 因子筛选怎么做（完整流程）

### 4.1 准备：宇宙、滞后、清洗

1. **Universe**：流动性、停牌、ST、涨跌停可成交性过滤  
2. **Point-in-time**：严禁未来函数；财报/另类数据必须按可知时点对齐  
3. **清洗**：去极值（winsorize）、缺失处理、标准化  
4. **中性化**：行业/市值/常见风格中性，避免「伪 alpha」  
5. **方向约定**：明确越大越好还是越小越好，评估时统一方向

### 4.2 单因子评估

核心指标建议同时看「统计」与「经济」两面：

- **RankIC / ICIR**：预测力与稳定性  
- **分层收益单调性**：避免只靠极端组贡献  
- **覆盖率**：过低则不可规模化  
- **换手**：过高则成本吞噬 alpha  
- **成本后多空夏普**：接近实盘真相的第一张成绩单

合格阈值应配置化（不同资产、不同频率不同），并随容量目标调整。

### 4.3 多重检验与样本外

推荐最小组合：

1. 全样本检验  
2. 滚动窗口稳定性  
3. 时间切分样本外（如 70/30 或 walk-forward）  
4. 市场状态切分（趋势/震荡、高波动/低波动）  
5. BH-FDR 或更保守的 BY 校正  

只有「样本内好看」但样本外翻脸的因子，默认不进入合成白名单。

### 4.4 冗余压缩

常用三步：

1. 相关聚类：同一簇只留代表元（如 ICIR 最高）  
2. 正交化：对存量因子回归取残差，保留增量信息  
3. 增量贡献：加入合成后，效用/信息比率是否显著提升  

目标不是因子数量多，而是**有效自由度**足够且可解释。

### 4.5 入库与持续监控

入选后立即绑定监控：

- IC 衰减 / 符号翻转  
- 覆盖率骤降  
- 风格暴露漂移  
- 与拥挤度指标同步上升  

触发阈值后自动降权或暂停进入当日合成。

## 5. 因子智能合成是什么

### 5.1 定义

因子智能合成（Intelligent Factor Synthesis）是指：在筛选后的白名单内，用**可解释规则 + 统计学习 + 状态自适应**的方法，把多个单因子映射为一个综合因子（或少数正交合成因子），使其在预测力、稳健性、可交易性上优于简单等权/拍脑袋加权。

它回答的不是「哪个因子最好」，而是：

> 在当前市场状态与风险约束下，这组因子应如何组合，才能形成更稳的可交易信号？

### 5.2 「智能」体现在哪里

| 能力 | 含义 | 例子 |
|------|------|------|
| 自适应加权 | 权重随近期有效性变化 | 滚动 ICIR 加权、贝叶斯收缩 |
| 状态条件 | 不同 regime 用不同配方 | 高波动降动量、抬升质量 |
| 冗余感知 | 相关升高时自动降权 | 相关惩罚、正交后再合成 |
| 约束内优化 | 合成目标含换手/回撤/暴露 | 效用最大化而非只最大化 IC |
| 可解释闸门 | 拒绝黑箱不可审计配方 | 权重区间、符号约束、逻辑审查 |
| 闭环反馈 | 净值/风控结果回写合成 | 回撤期收缩激进因子暴露 |

### 5.3 合成与策略层信号合成的边界

- **因子智能合成（本层）**：产出「综合因子/复合 alpha」，仍属于特征层，强调信息提炼与稳健性。  
- **策略生成中的信号合成**：在综合因子之上做选股、仓位、调仓与交易约束。  

实践中可以共用加权引擎，但版本、验收口径、风控挂钩要分层管理，避免职责混乱。

## 6. 为什么因子智能合成重要

### 6.1 单因子时代已经不够

单个因子 alpha 衰减更快、拥挤更严重。合成的价值在于：

- 提取互补信息（价值 + 质量 + 微观结构）  
- 平滑单因子阶段性失效  
- 在同等换手下提高信息比率  

### 6.2 等权并不「无害」

等权看起来中性，实则假设「每个因子同等有效且同等稳定」。这在现实中几乎不成立。  
智能合成把「近期有效、低相关、可交易」显式编码进权重。

### 6.3 让风控可前置

若合成阶段就纳入：

- 最大单因子权重  
- 风格暴露预算  
- 预期换手上限  

则策略层不必事后拼命补救，净值路径更平滑。

### 6.4 提升可运维性

合成配方版本化后，可以回答：

- 今天信号变了，是哪个因子权重变了？  
- 回撤期是否自动降低了高换手因子？  
- 某因子下架后，合成是否平滑重分配？  

这对实盘审计与事故复盘至关重要。

## 7. 因子智能合成怎么做

### 7.1 输入与前置条件

必须先满足：

- 因子已通过筛选白名单  
- 已统一标准化与方向  
- 有滚动 IC/ICIR、相关矩阵、换手估计  
- 明确优化目标（如：样本外 RankICIR - λ·换手 - γ·相关惩罚）

### 7.2 常用合成范式（由稳到强）

#### A. 可解释线性合成（生产默认首选）

\[
F^{syn}_t = \sum_i w_{i,t}\, \tilde{f}_{i,t}
\]

权重示例：

1. **ICIR 加权**：\(w_i \propto |ICIR_i|\)，再归一化  
2. **收缩加权**：把样本 ICIR 向历史先验收缩，降低估计噪声  
3. **相关惩罚加权**：在最大化 \(w^\top \mu - \lambda w^\top \Sigma w\) 下求解（\(\mu\) 为预期 IC，\(\Sigma\) 为因子相关）

优点：稳定、可解释、易审计。  
缺点：对非线性交互刻画有限。

#### B. 正交合成 / 主成分信息提取

1. 对白名单因子做 PCA / 风险模型残差正交  
2. 只保留对收益有预测力的成分  
3. 再按成分 ICIR 加权  

优点：降冗余。  
注意：主成分经济含义变弱，需额外解释层。

#### C. 状态条件合成（Regime-aware）

1. 定义市场状态：趋势强度、波动、流动性、拥挤度  
2. 每个状态维护一套权重或因子子集  
3. 状态切换时做权重平滑，避免换手爆炸  

这是「智能」最常见、也最容易落地的形式。

#### D. 学习型合成（需更强防过拟合）

- Elastic Net / 梯度提升 / 浅层网络等  
- 必须配套：嵌套交叉验证、特征稳定约束、符号约束、成本后验收  
- 生产建议：学习型只生成「建议权重」，最终仍经可解释闸门裁剪

### 7.3 推荐落地流程（生产级）

```
白名单因子
  → 计算滚动 ICIR、相关矩阵、换手、覆盖
  → 初值权重（ICIR 或等权）
  → 相关惩罚 / 风险预算优化
  → 权重约束（上下限、符号、换手）
  → 状态调节（regime overlay）
  → 生成综合因子 F_syn
  → 样本外再评估（IC、分层、成本后）
  → 通过则冻结版本；失败则回退上版
```

### 7.4 合成验收清单（必须过）

- 样本外 RankIC / ICIR 不低于最优单因子（或有统计增益）  
- 相对等权合成有稳健提升（不是仅样本内）  
- 换手与成本后绩效可接受  
- 权重路径平滑，不出现极端抖动  
- 单因子下架后，合成可自动重分配且不崩  
- 经济逻辑可说明：为何某类因子在当前状态权重更高  

### 7.5 常见失败模式

| 失败 | 症状 | 对策 |
|------|------|------|
| 过拟合加权 | 样本内很强，样本外迅速衰减 | 收缩、正则、嵌套 CV |
| 相关共振 | 多个因子同向拥挤 | 相关惩罚、正交化 |
| 换手失控 | 权重日度大跳 | 权重平滑、调仓预算 |
| 黑箱不可审 | 无法解释持仓 | 强制线性可解释层 |
| 把风格当 alpha | 中性化后失效 | 合成前强制中性化验收 |

## 8. 筛选 + 合成的一体架构

### 8.1 职责划分

| 模块 | 职责 | 关键输出 |
|------|------|----------|
| Screening | 决定「谁能进场」 | 白名单、监控规则 |
| Synthesis | 决定「进场后如何组队」 | 综合因子、权重配方版本 |
| Strategy | 决定「如何交易综合因子」 | 持仓、调仓、约束 |
| Nav Risk | 决定「出问题时如何收缩」 | 降仓/冻结/下线事件 |

### 8.2 闭环

```
合成因子实盘表现
  → 归因到单因子贡献
  → 衰减因子触发降权/移出白名单
  → 重新筛选与再合成（灰度）
  → 新版本通过验收后切换
```

### 8.3 版本治理

建议对象都带版本：

- `factor_lib@YYYYMMDD`
- `screen_rule@vX`
- `synthesis_recipe@vY`
- `strategy_spec@vZ`

任一上游变更，下游必须重跑验收，不可静默生效。

## 9. 最小可行实践（MVP）

若团队从零开始，建议按这个顺序：

1. **先筛后合**：只做 RankIC/ICIR + 相关压缩 + ICIR 加权合成  
2. **再加状态**：引入波动/趋势两状态权重切换  
3. **再加约束优化**：相关惩罚 + 换手约束  
4. **最后才上复杂模型**：并始终保留可解释线性底仓  

MVP 成功标准：

- 合成因子样本外 ICIR > 等权合成  
- 成本后仍显著  
- 权重可解释、可回放

## 11. 一句话记忆

**筛选负责“别把假因子放进来”，合成负责“把真因子变成更稳的可交易信息”。**  
两者一起，才构成完整的智能因子层。
