# 智能量化策略设计框架

> 目标：以可复用、可审计、可迭代的方式，覆盖「因子筛选 → 策略生成 → 净值风控」全链路，支撑研究、回测、仿真与实盘一致的策略生命周期管理。

---

## 0. 总体架构

```
数据层 → 因子工厂 → 因子筛选引擎 → 策略生成引擎 → 组合构建
                                              ↓
                                    回测 / 仿真 / 实盘
                                              ↓
                                    净值监控与风控闭环
                                              ↓
                                    诊断反馈 → 因子/策略再训练
```

### 设计原则

| 原则 | 说明 |
|------|------|
| 研究生产同构 | 同一套因子与信号定义贯穿回测、仿真、实盘 |
| 防过拟合优先 | 分层样本外、多重检验、换手与成本约束内生化 |
| 风险前置 | 风控不是事后补丁，而是策略生成与持仓优化的硬约束 |
| 可解释可追溯 | 每个持仓变动可回溯到因子、信号规则与风控触发原因 |
| 闭环迭代 | 净值异常与因子失效自动触发诊断与再筛选 |

### 核心对象

- **Universe**：可交易标的池（含行业、市值、流动性过滤）
- **Factor**：标准化后的截面/时序特征
- **Signal**：由因子或规则映射得到的方向与强度
- **Strategy**：信号合成、调仓、仓位与约束规则的完整定义
- **Portfolio**：目标权重与实际持仓
- **NavBook**：净值、回撤、风险指标与事件日志

## 1. 因子筛选（Factor Screening）

### 1.1 目标

从候选因子库中，筛出**稳健、低冗余、具备经济含义、可实盘落地**的因子子集，作为策略生成的输入。

### 1.2 因子生命周期

1. **候选生成**：价量、基本面、另类、微观结构、宏观状态等
2. **清洗标准化**：去极值、缺失填充、行业/市值中性化、截面标准化
3. **单因子评估**：IC / RankIC、分层收益、换手、覆盖度、稳定性
4. **多重检验**：多重假设校正（BH/BY）、样本外分片、滚动窗口衰减
5. **冗余剔除**：相关性聚类、正交化、条件信息增益（incremental R²）
6. **入库与监控**：存活因子进入因子库，持续跟踪 IC 衰减与风格暴露漂移

### 1.3 评估指标体系

| 维度 | 指标 | 合格参考（可配置） |
|------|------|-------------------|
| 预测力 | 均值 RankIC、ICIR | \|RankIC\|≥阈值，ICIR≥阈值 |
| 单调性 | 分层多空收益、多空夏普 | 分层收益近似单调 |
| 稳定性 | 滚动 IC 波动、半衰期 | 滚动 IC 符号稳定占比高 |
| 可交易性 | 覆盖率、换手、冲击成本敏感度 | 覆盖率≥阈值，成本后仍显著 |
| 独立性 | 与存量因子相关、VIF | 冗余度低于阈值 |
| 风险属性 | 风格暴露、尾部贡献 | 暴露可解释且可控 |

### 1.4 筛选流水线（建议流程）

```
候选因子
  → 数据质量闸门（覆盖率/异常值/滞后性）
  → 单因子检验（全样本 + 滚动窗口）
  → 多重检验校正（控制 FDR）
  → 样本外分片验证（时间切分 / 市场状态切分）
  → 冗余压缩（聚类代表元 + 正交化）
  → 组合增量贡献检验（加入后是否提升策略效用）
  → 输出：入选因子清单 + 权重先验 + 失效预警阈值
```

### 1.5 智能增强点

- **自适应中性化**：按市场状态切换行业/市值/波动中性化强度
- **因子衰减检测**：CUSUM / 滚动 IC 断点检测，触发降权或下架
- **LLM/规则辅助**：对因子经济逻辑做文档化审查，拒绝纯数据挖掘因子直接入选
- **状态条件筛选**：牛/熊/震荡市分别评估，保留 regime-conditional 因子

### 1.6 输出产物

- `selected_factors.json`：入选因子、方向、中性化方案、有效区间
- `factor_report.md`：IC、分层、相关矩阵、失效风险说明
- `factor_monitor_rules.yaml`：监控阈值与自动降权规则

## 2. 策略生成（Strategy Generation）

### 2.1 目标

把筛选后的因子转化为**可执行、可约束、可回测**的策略定义：信号合成、选股/择时、仓位、调仓频率与交易成本模型。

### 2.2 策略模板库

| 模板 | 适用场景 | 关键构造 |
|------|----------|----------|
| 截面多空 | 股票/期货截面选股 | 综合得分排序，多头/空头分层 |
| 多头增强 | 相对基准超额 | 基准内超配/低配，跟踪误差约束 |
| 时序择时 | 指数/品种择时 | 因子阈值或状态机切换仓位 |
| 事件驱动 | 公告/财报/异动 | 事件窗口进出场与冷却期 |
| 组合叠加 | 多策略账户 | 策略权重动态分配 |

### 2.3 生成流程

```
入选因子 + 市场约束 + 风险预算
  → 信号合成（线性加权 / 非线性模型 / 规则树）
  → 候选组合生成（参数网格 / 贝叶斯优化 / 进化搜索）
  → 硬约束过滤（流动性、行业、单票、杠杆、换手）
  → 效用评估（收益、回撤、换手、成本后夏普、稳健性）
  → 过拟合防线（样本外、嵌套交叉验证、deflated Sharpe）
  → 输出：策略说明书 + 参数冻结版本 + 回测档案
```

### 2.4 信号合成方式

1. **可解释线性合成**：按 ICIR 或风险调整权重加权，适合生产优先
2. **正则化模型**：Ridge / Elastic Net，控制因子拥挤与共线
3. **非线性模型**：树模型 / 浅层网络，必须配套特征稳定性和解释性闸门
4. **规则增强**：在模型分数上叠加事件过滤、涨跌停/停牌处理、黑名单

### 2.5 仓位与调仓

- **目标权重**：得分映射为权重（rank → weight，或 mean-variance / risk-parity 变体）
- **调仓触发**：固定周期 + 阈值突破 + 风控强制调仓
- **执行模型**：涨跌停不可成交、最小手数、冲击成本、滑点
- **换手预算**：日内/周度换手上限，超出则收缩调仓幅度

### 2.6 智能生成约束（防「好看不可用」）

- 必须报告**成本后**绩效，而非毛收益
- 必须报告**参数敏感性**与邻域稳定性
- 必须通过至少一段独立样本外与一次压力情景
- 策略版本语义化：`strategy_id@version`，参数与数据版本一并冻结

### 2.7 输出产物

- `strategy_spec.yaml`：宇宙、信号、调仓、约束、成本模型
- `backtest_summary.json`：绩效、归因、换手、暴露
- `promotion_checklist.md`：晋级仿真/实盘的验收清单

## 3. 净值风控管理（NAV Risk Control）

### 3.1 目标

对策略净值与持仓进行**事前限额、事中监控、事后归因**，保证回撤可控、尾部风险可解释、异常可自动处置。

### 3.2 三层风控体系

| 层级 | 时机 | 典型手段 |
|------|------|----------|
| 事前 | 下单前 | 单票/行业/风格/杠杆/流动性限额；风险预算；禁止清单 |
| 事中 | 交易日中 | 实时回撤、波动、敞口漂移、成交异常、关联暴露 |
| 事后 | 收盘后 | 归因、VaR/ES 回测检验、因子失效、策略降权/停用 |

### 3.3 净值侧核心指标

- **收益风险**：累计净值、日/周波动、夏普、Sortino、Calmar
- **回撤**：当前回撤、最大回撤、回撤持续期、水下时间
- **尾部**：历史 VaR / ES、压力情景损益
- **稳定性**：滚动夏普、绩效衰减、策略相关性矩阵
- **执行质量**：滑点、成交率、拒绝单、冲击偏离

### 3.4 处置动作（建议分级）

| 级别 | 触发条件示例 | 动作 |
|------|--------------|------|
| L1 预警 | 回撤触及软阈值 / 波动抬升 | 告警、提高监控频率 |
| L2 降仓 | 回撤或 VaR 突破 | 按风险预算统一降杠杆/降仓 |
| L3 冻结调仓 | 指标严重偏离或数据异常 | 停止开仓，仅允许减仓 |
| L4 策略下线 | 连续失效或风控模型失效 | 清仓或切换备用策略，进入复盘 |

### 3.5 净值风控闭环

```
实时/日终净值计算
  → 指标计算与阈值比对
  → 触发规则引擎（可配置）
  → 生成处置指令（降仓/停开/切换）
  → 执行并写审计日志
  → 归因诊断（市场 / 风格 / 因子 / 交易）
  → 反馈至因子筛选与策略再生成
```

### 3.6 与策略生成的耦合点

- 策略优化目标应直接包含：`效用 = f(收益, 回撤, 换手, 尾部风险)`
- 风险预算（波动、回撤、行业暴露）作为生成阶段硬约束
- 实盘触发 L2+ 后，自动降低该策略在组合层的分配权重

### 3.7 输出产物

- `risk_limits.yaml`：限额与分级动作
- `nav_daily.parquet`：净值与指标时序
- `risk_events.log`：触发、动作、恢复记录
- `attribution_report.md`：回撤/超额归因

## 4. 端到端编排

### 4.1 日终标准作业流程（EOD）

1. 拉取行情/基本面/成交与持仓核对
2. 更新因子值并运行质量检查
3. 因子监控：IC、覆盖、暴露漂移
4. 生成/更新目标组合（若未冻结调仓）
5. 风控预检 → 下发订单或仿真单
6. 更新净值簿记与风险事件
7. 产出日报：绩效、风险、异常清单

### 4.2 研究到生产晋级门禁

| 阶段 | 门禁 |
|------|------|
| 研究 | 单因子与策略通过样本内基础检验 |
| 回测验收 | 成本后绩效、稳健性、约束满足 |
| 仿真 | 至少覆盖完整调仓周期与异常日 |
| 小资金实盘 | 执行质量达标，风控事件可解释 |
| 扩容 | 容量评估通过，冲击模型校准 |

### 4.3 配置驱动

所有阈值、模板、限额以配置文件管理，代码只实现引擎；任何生产变更必须版本化并留下审批记录。

## 6. 最小验收标准

- 因子筛选能基于 IC/ICIR/相关性输出稳定入选集合
- 策略生成能产出带约束的 `strategy_spec` 与可解释权重
- 净值风控能根据回撤/波动阈值触发 L1–L4 动作
- 全流程关键步骤可单测，配置与结果可序列化审计
