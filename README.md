## 设计要点

1. **碳积分（CP）**作为统一计量货币，串联方法学、专利、协会奖项、可核证减排四条赛道。  
2. **即时入账 + 年度兑付**，解决激励周期过长问题。  
3. **项目部账户 + 个人分润**，并与绩效考核、评优晋升、资源倾斜挂钩。  
4. **必做清单门槛 + 造假一票否决**，保证数据可核验。  
5. **先试点后推广**，用实证校准积分分值与兑付汇率。
