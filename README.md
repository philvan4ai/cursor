# 研究A：动力电池政策博弈与气候装机均衡

参照研究B（技术灵活性与金属节制）的叙事骨架，整理动力电池限制政策的博弈逻辑，并用演化博弈求解不同气候情景下的装机平衡点。

## 核心问题

> 在不同气候情景（STEPS / APS / NZE）下，各国产业政策与电池产能策略互动收敛后，全球实际能实现多少动力电池装机？与情景目标装机的缺口有多大？

对照研究B：「优化技术组合后，还有哪些金属仍受采矿能力约束？」——B 问金属清单能否收缩；A 问装机均衡能达到何处。

## 叙事逻辑（B式）

成功的能源转型对减缓气候变化至关重要，但转型速度高度依赖动力电池装机的快速扩张。各国为推进电气化大力发展动力电池产业、提高产量；与此同时，为争夺市场竞争优势，又密集出台关税、关键矿产保护、市场准入与本地内容等限制政策。主流气候情景通常把所需装机量写成外生目标，却较少处理这些「本意服务转型」的产业政策经策略互动后如何分割供应链、抬高成本并压低全球有效供给。在这里，我们对最严格的脱碳路径（及 STEPS/APS 对照）展示：一旦允许政策侧在开放与限制之间、产业侧在全球一体化与碎片化本地化之间演化，博弈均衡下的实际装机可显著低于情景目标；关键杠杆是关税—矿产—准入摩擦叠加、产业租金私有化与气候收益公共品属性所驱动的限制竞赛。协同治理虽能把均衡推回接近目标的装机水平，但在缺乏协调时，限制政策本身会成为气候目标的制度性瓶颈。

## 模型一眼看懂

| 符号 | 含义 |
|------|------|
| \(r\) | 限制性产业政策份额 |
| \(f\) | 碎片化本地化产能份额 |
| \(\tau,\mu,a\) | 关税 / 矿产保护 / 市场准入强度 |
| \(Q^*(t;\alpha)\) | 气候情景目标装机 |
| \(Q=Q^*\eta\) | 博弈均衡下的实际装机 |

基准叙事：限制竞赛在 APS/NZE 下可形成高 \(r,f\) 均衡，2030 实际装机显著低于目标（缺口约 45%–50%）。
